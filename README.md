# FONTE — projet Android

Ce dépôt est préparé pour importer le projet de l'application Fonte depuis `Fonte-projet-android.zip`.

## Import du projet sur GitHub
1. Cliquer sur **Add file → Upload files** et déposer l'archive `Fonte-projet-android.zip` à la racine du dépôt.
2. Valider avec **Commit changes** sur `main`.
3. Le workflow **Importer Fonte Android et compiler l'APK** décompresse le ZIP, place les 51 fichiers source à la racine, supprime l'archive et le workflow temporaire, puis construit l'APK.
4. L'APK apparaît dans **Actions → dernier run → Artifacts → fonte-apk**.

Après import, ce README sera remplacé par la documentation du projet.
